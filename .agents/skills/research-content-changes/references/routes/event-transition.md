# Event and Transition change

An Event owns a sourced occurrence with temporal and geographic bounds. Record
what happened through description Statements; do not encode turning-point or
causal significance in the Event label.

A Transition connects bounded before and after Case Episodes through one or
more Events and identifies the relationships that changed. Put explanation and
rival causal interpretations in separate Statements. Validate that every
episode belongs to the same Case and that dates, places, Events, changed
relationships, and supporting Statements resolve.
