# Concept change

A Concept is an independently addressable, reusable, and contestable idea. Give
it a preferred label, one or more Concept Schemes, a scoped definition, and a
scope note that prevents predictable category errors.

Do not make one record serve as a Concept, attributed End, institutional Means,
Approach, or measured Case feature merely because ordinary language uses the
same label. Connect those distinct records through explicit, sourced
relationships. Use broader or narrower links only for defensible conceptual
generality; they are navigation claims and do not cause inheritance.
