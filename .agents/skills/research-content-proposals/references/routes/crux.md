# Crux proposal

A crux is a recurring problem or question that meaningfully differentiates how
systems work. It is not a topic label or a disguised preferred outcome.

In `content`, include:

```json
{
  "question": "A neutral comparative question ending in ?",
  "scope": "What falls inside and outside the crux",
  "valueLaden": false,
  "inclusionRationale": "Why this question is distinct and comparison-worthy"
}
```

Compare the candidate with all existing crux titles and questions. Flag overlap
in `duplicateCandidates`. If the distinction depends on a value judgment, set
`valueLaden` and explain the normative choice in a value-judgment claim.
