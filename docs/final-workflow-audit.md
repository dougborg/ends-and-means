- Agent delivery: quiet `pnpm --silent execution:run`/`execution:status` with explicit private authority/store, real terminal event and allowlisted public output; exact emitted marker bytes are checked through the actual matcher before separately authorized publication.
- Research-only and fresh brief consumer: use the shared evidence policy and versioned brief, preserve inspected/lead/inaccessible distinctions, inspect passages actually used and keep publication/promotion separate from completed fields.
- Failure/interruption and pause/resume: exercise actual child outcomes and bounded unknown cleanup through the recorder fixtures, plus explicit simulated delivery-mode transitions through the existing snapshot validator. Simulation is not an actual user pause or an authorization grant.
- Build/test/execution/production: the same pins and guarded commands apply; local three-worker and hosted automatic profiles are intentionally different. Static production deploys the verified `dist` artifact without a server or rebuild; matching hashes alone do not prove deployment.

Independent fresh-consumer walkthrough evidence and actual candidate command outcomes are reviewed separately from this matrix. Exact marker grammar, capability deletion coverage, source fitness, coverage floors, timeouts, independent review, hosted security and post-merge cleanup remain required.
