# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue or pull
request. Use GitHub's **Security** tab and select **Report a vulnerability** to
open a private security advisory with the maintainers.

Include the affected page, workflow, dependency, or commit; reproduction steps;
the likely impact; and any suggested mitigation. We will acknowledge a report
as soon as practical, investigate it privately, and coordinate disclosure after
a fix is available.

This repository deploys only from the protected `main` branch after its required
quality and security checks pass.
