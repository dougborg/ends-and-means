# Compiled Approach graph

`graph.json` is the current graph consumed by public routes. It is produced from
the complete first-pass migration of the exploratory comparison matrix into the
accepted analytical structure. It is generated by
`npm run migrate:framework`; do not edit it directly.

The graph schema is canonical, but most inherited records retain an explicit
`unreviewed-migration` lifecycle state and require research. Schema acceptance
does not promote their prose. Historical examples remain separated into
research notes, and former evaluative labels exist only in the migration audit at
`generated/reports/framework-migration.json`.

The social-democratic evidence file remains a temporary companion until its
complete trace is folded into the canonical graph under issue #47. Promotion of
individual records requires source review, Statement-level citations, bounded
Cases, and pull-request review under `docs/analytical-framework.md`.
