# Framework migration draft

`draft.json` is the complete first-pass migration of the exploratory comparison
matrix into the replacement analytical structure. It is generated by
`npm run migrate:framework`; do not edit it directly.

The artifact is deliberately non-canonical and is not yet rendered on public
routes. Its inherited prose is marked as unreviewed editorial material that
requires research. Historical examples have been separated into research notes,
and the former evaluative labels are recorded only in the migration audit at
`generated/reports/framework-migration.json`.

Promotion requires source review, claim-level citations, bounded cases, and
editorial approval under `docs/analytical-framework.md`.
